# План 11: QA, аудит доступности, нагрузочное тестирование и релиз

> **Этап roadmap:** Этап 7 (QA, полировка, релиз) · **Длительность:** 1 неделя · **Зависимости:** [Планы 04–10](00_Обзор_и_навигация.md)
> **Результат:** пройдены стресс-тесты граничных состояний, кросс-девайсная проверка (включая iPhone Safari WebView), автоматический аудит Lighthouse/axe, доведены онбординг и экран диагностики, подключены мониторинг и бэкапы БД — приложение готово к релизу.

---

## 1. Ключевые задачи исполнения

1. **Онбординг, песочница и полировка настроек:**
   - Онбординг-оверлей (3 экрана с кнопкой «Пропустить» и прогрессом «Шаг 1 из 4» + интерактивный тур с coach marks).
   - Песочница жестов: сброс после каждого жеста, haptic-отклик, `role="group"` и `aria-live="polite"`.
   - Экран диагностики в настройках: версия приложения, дата последнего сохранения, просмотр/очистка лога ошибок, «Экспорт диагностики» для баг-репортов, режим экономии трафика (`navigator.connection.saveData`).
   - Проверка `privacyScreen` (логотип/текст, задержка 100 мс, не блокирует загрузку при `document.hidden`).
2. **Тесты и локальный CI:**
   - Написать тесты: `escapeHtml` на XSS, интеграционные тесты свайпа, smoke-тест полного пользовательского сценария.
   - Настроить pre-commit / локальный скрипт полной проверки (`lint` + `typecheck` + `test` + `build`). *(Пункт 565 про GitHub Actions адаптируется под локальные скрипты, т.к. GitHub не используется.)*
   - Подключить `window.onerror`, `unhandledrejection`, структурированное логирование (Sentry без утечки PII).
3. **Стресс-тестирование граничных случаев:**
   - `0` привычек, `50` привычек, названия `80–100` символов (с переносом и без переполнения), серия `999` дней, день `0%` и `100%`, пустая база, битые данные при импорте, `400% zoom` reflow (WCAG 1.4.10).
4. **Кросс-девайс, Lighthouse, axe-core и прод-готовность:**
   - Тест на реальных устройствах: **iPhone (Safari WebView — приоритет №1 для проверки конфликта свайпа «назад»)**, Android, Desktop, планшет.
   - Замер метрик приёмки: Performance `≥ 90`, Accessibility `≥ 95`, LCP `≤ 2.5 с`, JS `≤ 60 КБ` gzip, CSS `≤ 15 КБ` gzip, `axe` нарушений = `0`.
   - Проверить PWA-метатеги и манифест (для fallback в браузере), автоматические бэкапы Postgres и алерты.
