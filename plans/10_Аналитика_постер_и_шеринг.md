# План 10: Аналитика, тепловая карта, PNG-постер и шеринг

> **Этап roadmap:** Этап 6 (Аналитика, постер, шеринг) · **Длительность:** 1 неделя · **Зависимости:** [План 05](05_Экран_Сегодня_и_свайп_механики.md), [План 06](06_Стрики_щиты_и_психология_привычек.md)
> **Результат:** экран «Анализ» показывает точные метрики за 7/30/месяц/всё время, оптимизированную тепловую карту года, график дней недели, «суперсвязь» энергия × выполнение, архетип месяца и генерирует реальный PNG-постер для Telegram Stories без утечки инкогнито-привычек.

---

## 1. Ключевые задачи исполнения

1. **Чистый модуль аналитики (`analyticsView.js`) и производительность:**
   - Мемоизировать `getPeriodDateKeys()` по периоду и дате.
   - Вынести `calculateSuperlinkInsight` в чистую функцию; все рендер-функции принимают данные параметром, не читая глобальный `state`.
   - Добавить skeleton-загрузку и понятное пустое состояние с CTA («Добавь привычки, чтобы увидеть статистику»).
   - Плавный cross-fade / View Transitions API между табами без мигания.
2. **Визуализация и доступность графиков:**
   - **Годовая тепловая карта (364 ячейки):** виртуализация / `content-visibility` / `IntersectionObserver`, `<button>` вместо `<div>`, `aria-label` с полным названием месяца и статусом, клавиатурная навигация стрелками, легенда (`full / plan_b / пусто`), подписи месяцев сверху и дней недели слева.
   - **Дни недели (`weekday-bars`):** линия среднего значения, скругление столбцов только сверху, высота до `72px`, текстовое описание под графиком для скринридеров.
   - **«Суперсвязь» и «честный разбор»:** мини-график вместо сухого текста, `aria-live` / текстовое резюме, сортировка «привычек-якорей» по проценту, фильтр по причине пропуска, прогресс-кольцо вокруг архетипа месяца.
3. **Генерация PNG-постера и шеринг в Telegram Stories:**
   - Рисовать постер на `Canvas` / `OffscreenCanvas`, экспортировать через `canvas.toBlob` (вместо `toDataURL`), освобождать ссылки через `URL.revokeObjectURL`.
   - **Приватность:** жёстко исключать/маскировать привычки с флагом `incognito` до генерации постера.
   - Содержимое постера (с настройкой «что включать»): дата генерации, имя/аватар (опционально), мини-график недели, подпись, опциональный водяной знак.
   - Загрузка постера на сервер / получение media URL → вызов `Telegram.WebApp.shareToStory(mediaUrl)` или `navigator.share` / отправка в чат.

## 3. Критерии готовности (Definition of Done)

- Тепловая карта на 364 дня прокручивается без просадок FPS и доступна с клавиатуры.
- Инкогнито-привычки никогда не попадают на PNG-постер и в шаринг.
- Постер генерируется в PNG через `toBlob`, скачивается/отправляется в Telegram Stories (`shareToStory`) и освобождает объектные URL.
