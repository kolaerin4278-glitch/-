# План 01: Подготовка, Telegram-бот и скелет репозитория

> **Этап roadmap:** Этап 0 (Подготовка) · **Длительность:** 3–5 дней · **Зависимости:** нет
> **Результат:** зафиксирован scope MVP, зарегистрирован бот и Mini App в `@BotFather`, настроен домен и HTTPS, готова политика конфиденциальности и каркас монорепо с настроенными линтерами и TypeScript.

---

## 1. Ключевые задачи исполнения

1. **Фиксация границ MVP:**
   - Подтвердить состав MVP (см. [`00_Обзор_и_навигация.md`](00_Обзор_и_навигация.md)) и перенести всё вне MVP в [`12_Бэклог_v1_1_и_дальнейшее_развитие.md`](12_Бэклог_v1_1_и_дальнейшее_развитие.md).
2. **Telegram и инфраструктура:**
   - Создать бота через `@BotFather`, получить токен (хранить только в `.env`, не коммитить).
   - Настроить Web App URL (HTTPS-домен), выбрать хостинг с учётом целевой аудитории (например, Cloudflare Pages / Netlify для статики + управляемый Postgres / Supabase / VPS под РФ-аудиторию).
3. **Юридика и приватность (обязательно для Telegram Mini App):**
   - Подготовить страницу/документ с политикой конфиденциальности и согласием на обработку данных.
   - Закрепить принцип минимизации PII: сохранять только `tg_id`, часовой пояс (`tz`) и настройки; отказаться от сторонних рекламных/аналитических трекеров.
4. **Скелет монорепозитория:**
   - Развернуть структуру: `apps/web` (Vite + TS), `apps/api` (Fastify), `apps/bot` (grammY), `packages/shared` (общие типы и константы).
   - Настроить `ESLint`, `Prettier`, `TypeScript` (strict mode) и локальные скрипты проверки (`lint`, `typecheck`, `test`).
   - GitHub не используется (прогресс ведётся в файлах планов).
